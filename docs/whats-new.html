The latest release, how to update, and anything you need to do afterwards.

0.8.0

31 October 2026

Works with Jellyfin 12. Jellyfin 12 rejected how earlier versions signed in, so on 0.7.6 nothing reached Jellyfin: the library never updated and new titles never appeared. Fixed, and Jellyfin 10.11 still works.

Also in this release

  • Stopping playback frees the stream right away, instead of waiting for it to time out.
  • sudo jellyfreedom webhook sets that up in Jellyfin for you, in one step.
  • Fewer interruptions: the VPN watchdog no longer restarts the streaming engine while something is playing.
  • Updates never go backwards: --update won’t replace a newer version with an older one.

Update

$ sudo jellyfreedom --update

After updating

  • If you use the playback-stop webhook, run sudo jellyfreedom webhook once.
  • On Jellyfin 12, if you turned EnableLegacyAuthorization back on to keep 0.7.6 working, turn it off again.
